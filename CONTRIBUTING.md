# Contributing

Thanks for your interest in contributing.

This project aims to remain a small, practical foundation for production-oriented modular approach to API contract design with reusable schemas, standardized error responses.

## Before you start

Before proposing a significant change, please open an issue or discussion describing:

- The problem you are trying to solve
- Why it belongs in this starter
- The proposed approach

The goal is to avoid turning the project into a collection of features that every application may not need.

## Development setup

Clone the repository and install dependencies:

```bash
git clone https://github.com/allydevs-engineering/openapi-api-contract-starter.git
cd openapi-api-contract-starter
npm ci
```
